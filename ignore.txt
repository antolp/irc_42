Main loop (en gros)

poll(...);

for each pollfd:
	if it is the listening socket:
		accept a new client (initialize Client)

	otherwise:
		find the corresponding Client using its fd

		if POLLIN:
			receive data into that Client's input buffer

		if POLLOUT:
			send data from that Client's output buffer

		if error or disconnection:
			remove that Client



Ownership (may add stuff):

Server
| -- owns listening socket
| -- owns all Client objects
| -- owns all Channel objects
| -- performs every accept(), recv() and send()
| -- interprets commands and coordinates state

Client
| -- owns one connected socket
| -- owns its input buffer
| -- owns its output buffer
| -- stores registration/identity state

Channel
| -- owns no socket and no Client
| -- stores non-owning client identifiers
| -- stores membership roles
| -- stores topic and channel modes

Command
| -- (immutable) representation of one parsed IRC line




new ownership transition acceptClient():

accept() creates fd
	->
Server temporarily owns fd
	->
setNonBlocking()
	->
new Client(fd)
	->
Client owns fd
	->
Server stores Client*
